### B. 定位声明 + 时间成本计 + 每游戏期望标注
1. 首页 hero 下新增一段"为什么做这个"：上表前三行事实。

3. 时间成本计：`localStorage['bar.timeMs']` 累计本站**可见**停留时长（`visibilitychange` hidden 即停，`pagehide` 落盘），首页与每个工具页底部显示：
   `你在本站已停留 X 分钟 ≈ 按快餐店柜台员法定最低时薪 S$12.04/h，少赚 S$Y`。
   不上传，与"所有计算都在本地完成"承诺一致。金额用整数分计算再格式化，不用浮点比较。
4. 断言（browser.py）：首页含上述三条事实原文；四张卡片各含其括号标注；时间计在 `page.clock` 推进 90s 后显示 `1 分钟` 且金额 = `S$0.30`（12.04 × 1.5/60 = 0.301 → 0.30）；hidden 状态下推进 60s 不累计；刷新后累计值保留。

### C. 视觉扑克牌（Codex 推荐方案 2：CSS 牌框 + 内联 SVG 花色）
- 统一 `cardHTML`：德州 rank+suit 双角标 + 中央花色 SVG；21 点/24 点无花色双角标牌，**不虚构花色**，21 点注明"10 含 J/Q/K"。
- 可见牌面 40×54 不变，点击外壳 44×54；21 点 tray 间距改 4px 保证 7 张不换行。
- 不引入外部资源；新增未压缩体积 ≤ 10KB。
- 断言：52 张牌 rank/suit/红黑独立核对；21 点/24 点不产生 suit；375×667 下德州录满 7 张原几何断言仍过；21 点 7 张不换行；前端变异（红桃↔方块互换、无花色变随机花色、牌高改 90px）各触发对应闸门。

### D. 手机适配 P0（有限范围）
- `.pill.sm` 与所有 `.pcard[data-i]` 触控 ≥ 44px 高；`touch-action: manipulation`。
- `installDock` 返回 dispose，切页时断开 observer/移除 listener（Codex P0 第三条）。
- **不动** `maximum-scale=1` 与对手数 8 键布局（改 stepper 会破坏点击预算，留第二阶段）。

### F. 首页卡片按最近使用排序（业主 2026-09-11 追加）
- 进入任一工具时记 `localStorage['bar.lastUsed']`（工具 id → 时间戳）。首页卡片按最近使用降序，未用过的保持默认顺序。
- 只在渲染首页时排一次，停留首页期间不重排（避免卡片跳动）。
- 断言：清空存储 → 默认顺序 骰子/德州/21点/24点；点进 21 点再返回 → 21 点排第一，其余相对顺序不变；再点进 24 点返回 → 24 点第一、21 点第二；刷新后顺序保留。

### E. 闸门缺口（Codex §0）
- `build.sh` 的 SW 版本 hash 纳入 `app-shell.html`（本次改 CSS 必须触发 SW 更新）。
- `build.sh` 末尾接上 `python3 test/browser.py`（先出候选产物到临时目录，全过再覆盖 `site/`）。
